Nightly Invoice Automation

Every night at 7:00 PM, this checks for any house marked Done that hasn't been billed yet — no matter which day it was actually completed, so a house finished late (after 7pm, or the next morning) still gets caught on the very next run instead of getting missed. It automatically emails an invoice — the "Nightly Auto-Invoice — Unpaid" template if they still owe money, or the "Nightly Auto-Invoice — Paid Receipt" template if they're already paid in full. Houses flagged for a fix, or marked "Didn't Get To" by the crew, are skipped and never billed. Each house is only ever billed once, so there's no risk of a repeat send. Edit either template's wording anytime under Templates > Billing.

Runs the same billing check right now, on demand — works whether the automatic toggle above is on or off. Use this to send tonight's invoices yourself if you've turned automatic sending off.

    Employee Categories

    Custom labels like CEO, Warehouse, Sales, or Installers — separate from Role (which controls Crew/route access). An employee can belong to more than one category.

    Employee Names, Role & Pay

    Add each employee's name, then set their Role — Crew for install/fix/removal crews (they get the route map), or a custom label like Warehouse or Receptionist. Position is a free-text job title.     Role Templates

    Set up what a job looks like once — like Installer or Office — then just pick that template for each new hire instead of ticking boxes one person at a time.     Requests Without Dates

    Manage Crews

    Crew Reassignment

    Move someone to a different crew without changing their usual (saved) crew. Leave "Through" blank for a single day, or set it to keep the change in place for as long as you need — handy when you're covering someone's time off.
